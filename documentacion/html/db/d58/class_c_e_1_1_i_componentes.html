Descripción detallada

Clase base abstracta para todos los componentes de entidades.

Define la interfaz principal para el sistema de componentes. Todos los componentes derivados heredan de esta clase y se pueden adjuntar a objetos (Objeto) para proporcionar funcionalidad específica (transformación, renderizado, estadísticas, etc).

El motor utiliza un patrón de arquitectura basada en componentes (ECS - Entity Component System) para máxima flexibilidad y composición.
