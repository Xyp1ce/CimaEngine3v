\subsubsection*{template$<$typename T$>$\newline
class CE::\+\+IIterador$<$ T $>$}
Interfaz template para iteración sobre contenedores. 

Define los métodos necesarios para navegar sobre una colección de elementos de tipo genérico T, soportando movimiento hacia inicio, final, actual y siguiente.
